Door stickers

One sticker per session. Write each URL to an NFC tag (any NFC writer app does it) and stick it on the door with this card. Phones that don't do NFC can scan the QR code instead. Neither needs an app.

Phones can't open 127.0.0.1. For real stickers, start Crew with CREW_HOST=0.0.0.0 and put your laptop's network address here, e.g. http://192.168.1.20:8765.
