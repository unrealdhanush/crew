Good to know

Does Crew read our source code?

No. From your repos Crew keeps dependency names, basic metadata and short README quotes it uses as evidence. Source code is never read or stored.

Can it use private repos?

Yes, with a read-only token you paste on the Team page. The token travels with your requests, is never saved, and nothing fetched with it is cached. Not on GitHub? Upload a dependency file or run crew scan on your machine, which sends package names only.

Do attendees need an app?

No. A door sticker holds a web address. Phones with NFC open it with a tap, and everyone else scans the QR code on the sticker.

What if the venue Wi-Fi is awful?

Pages Crew has already fetched are kept for six hours, so a bad connection won't wipe out your demo.

What if the agenda page is blank when scraped?

Some agendas only appear in the browser. On the Organizer page you can point Crew at the blog posts that list the schedule instead, or load the sample agenda to try everything first.
